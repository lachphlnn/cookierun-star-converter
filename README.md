# 쿠키런: 킹덤 6성 체계 전환 계산기

브라우저에서 실행하는 팬 제작 계산기입니다. GitHub Pages에 올려 무료로 공개할 수 있습니다.

## 현재 구현된 기능

- 바람궁수 쿠키 / 달빛술사 쿠키 선택
- 기존 달성 단계 입력
- 현재 보유 영혼석, 과거 사용 영혼석, 현재 보유 초월영혼석, 과거 사용 초월영혼석 입력
- 공식 공지에 적힌 120% 환산 및 소수점 올림 계산
- 합산량 450개 초과분의 선택 상자 수 계산
- 계산 상세 내역 표시

## 중요한 제한

이 초기 버전은 **전환 후 최종 성급과 잔여 영혼석을 계산하지 않습니다.** 공식 공지의 환산 설명만으로는 모든 성급에 필요한 6성 체계 영혼석 임계값을 확정할 수 없으므로, 해당 값을 임의로 만들지 않았습니다. `data/cookies.json`의 `gradeThresholds`는 검증 전까지 `null`로 유지합니다.

또한 입력한 과거 사용량은 사용자가 직접 확인한 수량이어야 합니다. 현재 성급만으로 과거 사용량을 자동 추정하지 않습니다.

## 공식 자료

- 바람궁수 쿠키 (2026-07-02): https://hub.cookierun-kingdom.com/ko/news/updates/july-2-update-notice
- 달빛술사 쿠키 (2026-10-21): https://hub.cookierun-kingdom.com/news/updates/october-21-update-notice

공식 공지의 핵심 규칙:
- 현재 보유 중인 영혼석/초월영혼석과 과거 승급/초월에 사용한 수량을 합산
- 합산량의 120%로 환산
- 소수점은 올림
- 합산량 중 450개까지는 120%로 영혼석 환산하고, 450개 초과분은 초과한 각 단위에 대해 레전더리 영혼석 선택 상자로 계산
- 최종 성급은 기존 달성 단계와 환산 재료로 가능한 최대 단계 중 낮은 단계
- 전환 과정에서 추가 승급 재료는 요구하지 않음

## GitHub에 올리는 방법 (초보자용)

1. GitHub에 로그인하고 `New repository`를 선택합니다.
2. 저장소 이름을 `cookierun-star-converter`로 정합니다.
3. Public을 선택하고 저장소를 생성합니다.
4. 저장소에서 `Add file` → `Upload files`를 선택합니다.
5. 이 ZIP 파일의 압축을 풀고 **압축 해제된 파일과 폴더**를 업로드합니다. `index.html`은 저장소 최상위에 있어야 합니다.
6. `Commit changes`를 누릅니다.
7. 저장소의 `Settings` → `Pages`로 이동합니다.
8. `Build and deployment`에서 `Deploy from a branch`를 선택합니다.
9. Branch를 `main`, folder를 `/(root)`로 선택하고 저장합니다.
10. 잠시 기다린 뒤 Pages 화면에 표시되는 사이트 주소를 엽니다.

## 코드 수정 방법

GitHub에서 `app.js`를 열고 연필 아이콘(Edit)을 누르면 브라우저에서 수정할 수 있습니다. 수정 후 `Commit changes`를 누르면 Pages가 다시 배포됩니다.

## 테스트

Node.js가 설치되어 있다면 저장소 폴더에서 다음을 실행합니다.

```bash
node tests/conversion.test.js
```

테스트는 120% 환산과 450개 초과분 계산만 검증합니다. 성급/잔여 영혼석 계산은 아직 구현되지 않았습니다.
