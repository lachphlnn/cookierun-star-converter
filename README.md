# 쿠키런: 킹덤 6성 체계 전환 계산기

브라우저에서 실행하는 팬 제작 계산기입니다. GitHub Pages에 무료로 공개할 수 있습니다.

## 기능

- 쿠키 선택 없이 공통 전환 규칙 계산
- 기존 단계 선택을 10개의 클릭 가능한 별로 표시 (★1~★5, ★1초월~★5초월)
- 현재 남은 재료를 숫자 입력 또는 동기화된 슬라이더로 조절 (숫자 입력의 위·아래 화살표 유지)
- 선택한 등급에 따라 슬라이더 최대값과 재료 종류(영혼석/초월영혼석) 자동 변경
- 선택한 기존 단계까지 사용한 누적 영혼석/초월영혼석 자동 합산
- 공식 공지의 120% 환산, 소수점 올림, 합산량 450개 초과분의 선택 상자 계산
- 환산 재료로 가능한 성급과 기존 단계 상한을 비교해 예상 최종 성급 계산
- 최종 성급의 누적 필요량을 차감한 잔여 영혼석 계산

## 계산에 사용한 값과 주의사항

공식 공지에서 확인되는 규칙은 보유 재료와 과거 사용량의 합산, 합산량의 120% 환산(소수점 올림), 450개 초과분의 선택 상자 전환, 기존 달성 단계와 환산 재료로 가능한 단계 중 낮은 단계 적용입니다.

기존 단계별 누적 사용량과 6성 체계의 성급별 누적 영혼석 임계값은 커뮤니티 위키의 승급·초월 표를 바탕으로 입력했습니다. 누적 기존 영혼석은 해금 비용 20개를 포함해 `[0, 40, 70, 120, 190, 290, 290, 290, 290, 290, 290]`, 초월영혼석은 `[0, 0, 0, 0, 0, 0, 20, 50, 90, 140, 200]`으로 처리합니다. 새 체계의 누적 임계값은 기본 상태 0, ★1 40, ★2 80, ★3 150, ★4 250, ★5 380, ★6 540입니다.

이 단계별 표는 공식 공지 본문이 아니라 커뮤니티 위키를 근거로 하므로, 게임 내 전환 결과와 차이가 있다면 게임 내 결과를 우선해 주세요. 실제 게임의 개별 쿠키 처리 방식이 달라지면 `app.js`의 상수를 조정해야 합니다.

## GitHub Pages에 올리는 방법

1. GitHub에서 `New repository`를 선택하고 저장소 이름을 `cookierun-star-converter`로 지정합니다.
2. `Public` 저장소를 생성합니다.
3. 이 ZIP을 압축 해제한 뒤 **압축 해제된 파일과 폴더**를 저장소 최상위에 업로드합니다. `index.html`이 최상위에 있어야 합니다.
4. `Commit changes`를 누릅니다.
5. 저장소의 `Settings` → `Pages`로 이동합니다.
6. `Build and deployment`에서 `Deploy from a branch`, Branch `main`, Folder `/(root)`를 선택하고 저장합니다.
7. Pages 화면에 표시되는 사이트 주소를 엽니다.
